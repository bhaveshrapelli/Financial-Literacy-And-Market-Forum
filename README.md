# 📈 Financial Literacy & Market Forum

A modern financial education and market discussion platform designed to help users improve financial awareness, learn investment concepts, and participate in community-driven market discussions through an interactive web experience.

This project combines financial learning resources, market-related discussions, and user engagement features into one centralized platform.

---

# 🌐 Project Vision

Financial Literacy & Market Forum aims to bridge the gap between financial knowledge and practical market understanding by providing a platform where users can:

- Learn financial concepts
- Explore market basics
- Discuss investment strategies
- Share financial insights
- Improve money management awareness

The platform is built with a clean interface and scalable architecture suitable for educational and community-driven applications.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/bhaveshrapelli/Financial-Literacy-And-Market-Forum.git
```

---

## Move into Project Directory

```bash
cd Financial-Literacy-And-Market-Forum
```

---

## Create Virtual Environment

```bash
python -m venv venv
```

---

## Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## Install Required Packages

```bash
pip install -r requirements.txt
```

---

## Run Application

```bash
python app.py
```
